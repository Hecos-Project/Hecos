Package Repositories

Configure remote or local package repositories to fetch modules and playbooks from. Enter one or more full URLs (one per line). These links will be available in the Package Manager repository dropdown, allowing anyone to download packages from their desired repository (including non-GitHub sources, personal servers, local network endpoints, or custom hosts).

Supports HTTPS, HTTP URLs or local file paths. Empty lines or lines starting with # will be ignored.

Troubleshooting

If a package's UI is broken or it seems to be missing files after an update/reinstall, its manifest snapshot in the internal database may be corrupted. Use this button to clear the snapshot cache. Hecos will resync it from the installed files on disk on the next startup.
