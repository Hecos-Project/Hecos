Package Repositories

Configure remote or local package repositories to fetch modules and playbooks from. Enter Name | URL (or simply the URL, and a friendly name will be generated automatically). These repositories will appear in the Package Manager repository dropdown, and the active repository name will be displayed in the Store bar.

Syntax: Name | URL (e.g. Hecos Elite | https://github.com/Hecos-Project/Hecos-Elite). If only a URL is entered, a friendly name is automatically generated. Empty lines or lines starting with # will be ignored.
Only required if your repository is Private on GitHub. If public, leave empty.

Troubleshooting

If a package's UI is broken or it seems to be missing files after an update/reinstall, its manifest snapshot in the internal database may be corrupted. Use this button to clear the snapshot cache. Hecos will resync it from the installed files on disk on the next startup.
