# Autonomous Agent

This system app gives Hecos the ability to act independently. 

## Features
- **Planning & Execution**: Give it a high-level goal, and it will figure out what modules it needs, install them using `module_awareness`, and orchestrate the execution using `flows`.
- **Scheduled Behaviors**: Can set up cron-like schedules to execute behaviors periodically.
- **Reflection**: Can reason about its own capabilities and suggest improvements or missing modules.
- **Trust Controls**: Fully configurable from the Central Hub to require user confirmation for actions like auto-installs.
