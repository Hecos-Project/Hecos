# Voice Clone Reference Samples

Place your WAV reference audio files here for use with XTTSv2 voice cloning.

## Requirements
- Format: **WAV** (16-bit, mono or stereo)
- Duration: **10–30 seconds** recommended
- Content: Clean, single-speaker audio with minimal background noise
- Language: Match the language you intend to generate

## Usage
Files placed here will automatically appear in the Voice Clone dropdown in the XTTSv2 configuration panel.
