=============================================================
Hecos - Kokoro Models Directory
=============================================================
This directory is for local Kokoro neural TTS models and weights.

- By default, Hecos runs the built-in Kokoro-82M v1.0 model.
- If you have alternative or fine-tuned Kokoro models (.pth files
  or subfolders containing config.json and .pth weights), place
  them here.
- They will automatically appear in the Kokoro Model dropdown
  in WebUI -> Audio Settings -> Kokoro Engine.
=============================================================
